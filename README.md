# Magic Science Chest: Improved

A free passive-provider chest that supplies science packs after your force has produced enough of each pack.

**Factorio 2.1 · Version 1.0.2**

- Default unlock threshold: 100 produced packs of each type.
- Default chest supply: 200 of each unlocked pack.
- Uses native refill, with corrected filters, GUI updates and cached research checks.

## Installation

Disable magic-science-chest before enabling this fork. Existing chest names are retained.
